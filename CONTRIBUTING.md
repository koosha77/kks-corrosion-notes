# Contributing to kks-corrosion-notes

Thank you for your interest in this repository. These are personal study notes on **cathodic corrosion protection (KKS / Kathodischer Korrosionsschutz)** and concrete rehabilitation, maintained during my Master's studies at **Technische Hochschule Deggendorf**.

## Scope of contributions

Because this is a study-notes repo, contributions should stay close to the topic:

- Corrections of technical errors (electrochemistry, standards, formulas)
- Clarifications of German technical terms (e.g. *Passivierung*, *Chloridgehalt*, *Bezugselektrode*)
- References to relevant standards: **DIN EN ISO 12696**, DIN EN 1504, DIN EN ISO 8044
- Additional worked examples for half-cell potential mapping or chloride profiles

## How to contribute

1. Fork the repository
2. Create a feature branch: `git checkout -b notes/<short-topic>`
3. Keep Markdown files small and focused (one concept per file)
4. Use English as the main language, with German technical terms in *italics* and parentheses
5. Open a Pull Request with a short description and, if possible, a citation to a standard or textbook

## Style guide

- File names: lowercase, `snake_case.md`
- Headings: start at `#` per file, use `##` for sections
- Formulas: use LaTeX-style fenced blocks where helpful
- Always cite sources for normative values (e.g. potential thresholds, chloride limits)

## Code of conduct

Be respectful and constructive. This repository is a learning resource; corrections are welcome, condescension is not.
